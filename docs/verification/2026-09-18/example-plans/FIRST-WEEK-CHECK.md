# First week: daily prescriptions for every example

These are complete outputs from the local Stride engine, generated from the same 15 example inputs as the previous progression report. Only the sample runner and event names have been clarified. They are examples for checking the engine, not your personal profile. All start Monday 21 September 2026.

The input easy planning pace is 6:00/km. These profiles contain no race benchmark or explicit pace target, so the actual saved workouts prescribe effort; no faster pace has been invented. “≈” means a distance estimate for a timed or mixed workout. When a step has kilometres, those are its stopping condition; its time is a planning allowance. Follow steps in their listed order. Rest means no run is scheduled. Race duration is a planning estimate, not a predicted finish time. Weekly training totals exclude race day. Easy-day distances retain the exact generated values, including any small fractions.
