# Weekly progression examples

All weekly totals exclude race-day distance. Ordinary weeks preserve or build load; recovery and taper can reduce it. A quality count includes the long run. Rounding is for display only. A phase marked ‘taper begins’ contains the first race-relative taper day, even when the saved calendar phase remains Race preparation; its reduction is intentional.
